# Standard Settings Reference

## Audio Settings

| Setting ID | Default Value | Type | Description |
|------------|---------------|------|-------------|
| `audio_master` | `1.0` | Range (0.0-1.0) | Master volume control |
| `audio_music` | `1.0` | Range (0.0-1.0) | Music volume control |
| `audio_sfx` | `1.0` | Range (0.0-1.0) | Sound effects volume control |

## Gameplay Settings

| Setting ID | Default Value | Type | Description |
|------------|---------------|------|-------------|
| `gameplay_fov` | `70.0` | Range (40.0-120.0) | Field of view angle |
| `gameplay_sensitivity` | `0.5` | Range (0.0-1.0) | Mouse sensitivity |

## Graphics Settings

| Setting ID | Default Value | Type | Description |
|------------|---------------|------|-------------|
| `graphics_vsync` | `false` | Boolean | Enable/disable vertical sync |
| `graphics_fullscreen` | `true` | Boolean | Enable/disable fullscreen mode |
