# RoomSettings

Represents the configuration settings for a room, including the map, game mode, and any additional custom parameters (Modifiers).

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `Map` | `string` | The name or identifier of the map to be played. |
| `Gamemode` | `string` | The name or identifier of the game mode. |
| `AdditionalSettings` | `table` | A dictionary/table containing extra, custom settings for the room (e.g., time limits, friendly fire). |
